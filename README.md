# 4 Exercices de Base — Langage JavaScript (Pur Node.js)

Ces 4 exercices mettent en pratique les notions vues dans les présentations **Les Bases du Langage JavaScript** et **Séparation des Fichiers & Node.js** (sans navigateur ni DOM).

## Prérequis
- **Node.js** (version 18 ou supérieure) installé sur votre machine (`node -v`).

## Liste des exercices
1. `exercice-01-variables-types/` : `const` / `let`, `===`, `??`, `?.`, template literals, *early return*.
2. `exercice-02-fonctions-closures/` : fonctions fléchées `=>`, paramètres par défaut, `for...of`, *closures*.
3. `exercice-03-tableaux-objets-esm/` : séparation en modules ES (`import` / `export`), déstructuration, spread `...`, `.filter()`, `.map()`, `.reduce()`, `.find()`.
4. `exercice-04-async-erreurs/` : `Promise`, `async` / `await`, `try` / `catch` / `finally`.

## Comment travailler chaque exercice
1. Ouvrez le dossier de l'exercice dans votre terminal :
   ```bash
   cd exercice-01-variables-types
   ```
2. Lisez son fichier `README.md`.
3. Complétez les zones marquées `// TODO` dans le code.
4. Exécutez la vérification automatique :
   ```bash
   node verify.js
   ```
